## CN2 GIA 和 CN2 GT，差别在回程走哪条路

CN2 是中国电信的下一代承载网，AS4809。GIA（Global Internet Access）是这条线里的顶级产品，回程基本全部走 59.43 高速节点；部分省份没有接入 CN2 GIA 节点，会借道 202.97 普通骨干网。白天不丢包，晚高峰丢包率也极低。GIA 的价格定位高、用户少，所以平时带宽富余，体验比普通线路稳；代价是整体出口带宽偏小，一旦被攻击很容易出现波动。

GT 是另一档。国际段走 CN2，国内段可能切回 163 骨干网，便宜，高峰期拥堵概率明显更高。市面上很多标着“CN2”的便宜机器就是这一档。

有人会问去程要不要也走 GIA。出国方向本身不堵，电信前几年又对普通线路做过扩容，一般只需要确认**回程**是不是 CN2 GIA。这个判断对绝大多数建站和跨境访问场景已经足够。

### 下单后用 mtr 验一遍 59.43

商家说回程是 GIA，你得自己看一眼。机器开通后，从本地电脑对服务器 IP 跑 mtr 或 traceroute，重点看从服务器回你本地这一段有没有连续出现 59.43 开头的节点；如果一路都是 202.97，说明回程借道了普通骨干网。

## 哪档够用：按场景对号入座

**个人博客、Typecho/WordPress 小站**：1 核 1G、10G SSD、500GB 月流量那档就够。静态页面和小型数据库吃不了多少资源，500GB 流量对日均几百到一两千 IP 的文字站绰绰有余。年付 299 元，是这条线上最省的选择。

**中小型企业站、轻量 API 服务**：还是 1 核 1G，但把硬盘和流量放宽到 15G / 800GB 的 A2 档，年付 449 元。多出的 150 元买的是流量余量和更大的盘，跑几个小站点、挂个定时任务、放点日志文件不会碰到上限。

**图片多的电商站、外贸展示站**：带宽是瓶颈，不是 CPU。图片和素材加载吃的是持续吞吐，起步就往 A2 及以上走，必要时看 B1 档。这类站如果卡在最低配，访客等图加载的时间会直接反映在跳出率上。

**高并发应用、游戏服、中型数据库**：云服务器这条线的 1 核配置不适合，直接看独立服务器。伦敦那台双路 EPYC 7552、512G 内存的机器是给这类负载准备的，价格也是另一个量级。

关于带宽，恒创科技在其日本 CN2 产品页给过一组经验值：日均 1000 IP 以内 2M 够用，5000 IP 左右选 5M，1 万 IP 以上选 10M。这是商家口径，可以参考它反推自己的需求；AkkoCloud 这条线标称 500Mbps 端口，端口速度不是瓶颈，真正要算的是月流量额度。

## 哪些人其实不用买 CN2 GIA

预算压到极致、只是放个静态页面或跑个监控脚本，普通国际线路的便宜机器完全够用，GIA 多花的钱买不到对应的体感。

访客基本都在海外，国内访问只是你自己偶尔登一下后台，也没必要为回程优化付费。

需要中国大陆访问快但预算有限，可以看走 CMIN2 或联通 9929 回程的产品线，通常比三网 GIA 便宜。这类线路对移动、联通用户的优化更明显，电信用户的体验则不如纯 GIA。选之前先搞清楚你的访客里哪家运营商占多数。

## 常见问题

**电信CN2 VPS 需要备案吗？**
不需要。海外机房不受国内 ICP 备案管辖，开通即用。

**2M 带宽和 500Mbps 端口，到底看哪个？**
端口速度是峰值上限，月流量额度才是你会用完的东西。500GB/月摊到每天约 16GB，文字站和小型电商站正常运营碰不到；视频、下载、大图站要按实际访问量估算。

**晚高峰会不会掉速？**
CN2 GIA 的设计目标就是这个时段。第三方测评显示圣何塞方向延迟约 168ms，晚高峰未出现明显劣化。实际表现取决于你所在省份是否有 59.43 节点直连，所以还是要自己跑 mtr 验证。

**能拿来跑代理吗？**
各家条款不同，有的明确禁止。下单前读一遍服务协议，别把建站用途的机器拿去跑违规服务。

**年付之后第二年涨价吗？**
官网没有单独公示续费价，结算页会显示实际金额。首年活动价不等于长期价，做预算时按结算页的数字算。
